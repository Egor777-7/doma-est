## Что это

Сервис для семей, которые готовят дома. Человек выбирает блюда на неделю, а сервис собирает из них корзину продуктов и передаёт её в доставку продуктовой сети.

## Какую задачу решаем

Каждую неделю семья заново решает одно и то же: что готовить на несколько дней, кто что не ест, что уже лежит дома, сколько чего купить и как набрать всё это в приложении доставки. Корзина на неделю — это десятки позиций, которые сейчас придумывают, считают и набирают вручную.

## Как работает

1. **Семья.** Один раз указываются люди, их аллергии и то, что они не едят.
2. **Неделя.** По сроку, приёмам пищи и времени на готовку сервис предлагает план блюд. Любое блюдо можно заменить, видя новую сумму корзины, или закрепить.
3. **Запасы.** Сервис спрашивает только про продукты из этого меню, и подтверждённые остатки вычитаются из покупок.
4. **Покупки.** Граммы всех блюд суммируются и переводятся в упаковки магазина. Список собран по отделам, у каждого товара видно, для какого он блюда.
5. **Передача в доставку.** Список уходит в корзину сети в личном кабинете клиента.

## Технологический принцип передачи корзины

Расчёт идёт на устройстве пользователя. Сети передаётся только список «артикул + количество», без персональных данных. Корзина собирается в облаке сети в аккаунте клиента, а оплата, доставка и замены остаются у сети. До интеграции товары переносятся по шагам через ссылки на карточки товаров. После интеграции переносом станет одна ссылка на готовую корзину или запись в корзину после входа клиента в аккаунт сети.

## Как проверить дату

- **GitHub:** дата первого коммита и релиза `v1.0`.
- **OpenTimestamps:** хэши PDF и видео заверены в блокчейне Bitcoin; сами файлы никуда не отправлялись. Проверка: `pip install opentimestamps-client`, затем `ots verify doma-est-idea.pdf.ots` рядом с PDF. Подтверждение в блокчейне появляется через несколько часов после метки.
